# code-to-cpu

普段書いている高級言語のコードが、コンピュータ上でどのように実行されるのかを理解するための学習ログです。

Cなどの小さなコードをコンパイルし、生成されたアセンブリや機械語を観察しながら、CPU、レジスタ、メモリ、スタック、関数呼び出し、分岐、OSとの境界を実体ベースで学びます。

## ゴール

次のつながりを、自分の言葉で説明できる状態を目指します。

```text
高級言語 → コンパイラ → アセンブリ／機械語 → CPU／メモリ → OS
```

アセンブリそのものの習得ではなく、コードが実際にどのように処理されるかを追えるようになることが目的です。

## 進め方

各テーマについて、小さな検証コードと観察結果を記録します。

1. 確かめたいことを決める
2. 小さなCコードを書く
3. コンパイル結果と実行時の状態を観察する
4. 予想との違いや理解したことをメモする
